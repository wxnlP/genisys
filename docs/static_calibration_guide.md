# 静力学标定 — 数据采集操作手册

> 适用于 geniarm 六轴机械臂（DM4310/DM4340P 电机，MIT 控制模式）
> 目标：采集真实关节力矩数据，用于辨识连杆质量×质心参数，实现重力补偿

---

## 1. 前置准备

### 1.1 标定策略

推荐**分层标定**，一次工作，永久复用：

| 层次 | 内容 | 频率 | 耗时 |
|------|------|------|------|
| **裸臂标定** | 拆掉夹爪、相机等所有附件，标定机器人本体 link 1~6 | **仅一次** | ~1 h |
| **末端标定** | 装上附件后，走 5~6 个姿态快速辨识负载参数 | **换设备时** | ~5 min |

裸臂标定一次后，后续换夹爪、换相机，都只需做几分钟的末端快速标定，不用重新扫 6 个关节。

### 1.2 准备清单

```
□ 拆掉夹爪、相机等所有末端附件（裸臂标定）
□ 电机使能，MIT 模式
□ stiffness 设 30~50，damping 设 3~5
□ 所有 effort = 0（不补偿）
□ monitor 已连接，能看到 joint_state 数据
□ 机器人回到 home 位姿（所有关节 ≈ 0°）
□ 周围无任何障碍物
```

## 2. 需要记录什么数据

**每次采一个点，记录全部 6 个关节的数据，一个不能少。**

| 字段 | 来源 | 维度 | 说明 |
|------|------|------|------|
| `position[0..5]` | `joint_state` | 6 | 6 个关节角度 (rad) |
| `effort[0..5]` | `joint_state` | 6 | 6 个关节力矩 (N·m) |

> **为什么动一个关节也要记全部？** 机器人力矩是耦合的。动关节 2 时，$\tau_3$ 也会随 $q_2$ 变化（link 3 跟着摆动），这些耦合数据在参数辨识中提供了额外约束，能大幅提高精度。

CSV 格式示例（每行一个采样点）：

```
j1_pos, j2_pos, j3_pos, j4_pos, j5_pos, j6_pos, j1_eff, j2_eff, j3_eff, j4_eff, j5_eff, j6_eff
 0.00,   0.78,  -1.05,   0.00,   0.00,   0.00,   0.12,   3.45,   1.23,   0.05,   0.03,   0.01
```

## 3. 逐关节采集流程

### 核心原则

$$\boxed{\text{关节角度变化越大 → 力矩变化越明显 → 参数辨识度越高}}$$

- **准静态**：速度足够慢（≤0.15 rad/s），使惯性力可忽略
- **正反各一遍**：观察迟滞，判断摩擦大小
- **只取稳态数据**：MoveJ 到位后等待 0.5~1s，振铃衰减后再记录

### 3.1 关节 1 — 肩关节旋转

| 项目 | 值 |
|------|------|
| 范围 | $-150° \rightarrow +150°$ |
| 步进 | $10°$ |
| 点数 | 正反向各 31，共 62 |
| 其他关节固定 | q₂~q₆ = 0° |

**物理特性**：绕 $z_0$ 竖直轴旋转，$\tau_1$ 理论上恒定不变。

**主要目的**：
- 验证数据一致性（$\tau_1$ vs $q_1$ 应为水平直线）
- 检测零偏（直线若明显偏离 0，说明存在未补偿偏移）
- 摩擦估算

**预期**：
```
τ₁:   ────────  水平直线，波动应 < 0.2 N·m
τ₂~τ₆: ────────  水平直线（其他关节未动）
```

### 3.2 关节 2 — 肩关节俯仰 ⭐ 最关键

| 项目 | 值 |
|------|------|
| 范围 | $5° \rightarrow 180°$（留安全余量） |
| 步进 | $5°$ |
| 点数 | 正反向各 36，共 72 |
| 其他关节固定 | q₁=0°, q₃=0°, q₄=0°, q₅=0°, q₆=0° |

**物理特性**：

$$\tau_{2,\text{gravity}} \propto (m_2 r_{2z} + m_3 r_{3z} + \cdots) \cdot g \cdot \sin(q_2)$$

承载连杆 2~6 全部重力（总质量 ≈ 7.9 kg），力矩信号最强，峰值约 11.6 N·m。

**预期**：
```
τ₂:   ∩ 形正弦曲线，峰值在 q₂≈90°
τ₃:   ∩ 形正弦曲线（link3 耦合）
τ₁:   ─ 水平直线
τ₄~τ₆: 基本为 0
```

**峰值若偏移 90° → q₂ 的 offset 不准，需先校零。**

### 3.3 关节 3 — 肘关节

| 项目 | 值 |
|------|------|
| 范围 | $-150° \rightarrow -5°$（留安全余量） |
| 步进 | $5°$ |
| 点数 | 两组不同 q₂ 位姿，共约 124 |
| 其他关节固定 | **组 1**: q₂=45°  **组 2**: q₂=90° |

**关键技巧**：在**两组不同的 q₂ 位姿**下分别采集，避免 $q_2$ 和 $q_3$ 的参数耦合。

> 为什么 q₂ 不取 0°？q₂=0° 时前臂竖直向上，q₃ 变化对重力矩影响很小，信号微弱。

**预期**：
```
τ₃:   ∩ 形，峰值在 q₂+q₃ ≈ 90°~120°
τ₂:   随 q₃ 变化（总质心移动）→ 说明耦合约束有效
两组数据趋势一致且有一定偏移 → 采集成功
```

### 3.4 关节 4~6 — 腕关节

| 项目 | 值 |
|------|------|
| 范围 | $-90° \rightarrow +90°$ |
| 步进 | $15°$ |
| 点数 | 各约 26 |
| 其他关节固定 | q₁=0°, q₂=90°, q₃=-90°（水平伸出位姿） |

**特性**：腕部质量小、力臂短，重力矩峰值仅 0.5~1.0 N·m，信噪比差。

**处理**：若力矩变化 < 0.1 N·m（被噪声淹没），**直接使用 CAD 名义值**即可，接受。

## 4. 数据异常排查

采集完成后，画 $\tau_i$ vs $q_j$ 曲线图快速判断数据质量：

### 4.1 异常模式速查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| $\tau_1$ 波动 >0.2 N·m | 振动 / CAN 噪声 | 增加平均帧数；检查 CAN 终端电阻 |
| 正反向曲线明显分离 | 库仑摩擦大 | 在动力学模型中加入摩擦项 |
| $\tau_2$ 峰值不在 90° | q₂ offset 不准 | 先校准关节零位 |
| $\tau_2$ 曲线非正弦 | 运动学参数错误 | 检查 MDH 参数 |
| q 变化但 $\tau$ 不变 | 关节后连杆质量太小 | 换一个位姿再采，或接受名义值 |
| $\tau_3$ 两组数据几乎重合 | q₂ 差异不够大 | 改用 q₂=45°/135° |
| 采集时机器人抖动 | stiffness 太低 | 提高到 60，或增大 damping |
| 特定角度剧烈振动 | 接近奇异点 | 跳过该角度附近的点 |

### 4.2 数据质量判定标准

```
τ₂ 曲线:
  ✅ 光滑正弦，正反向偏差 < 0.5 N·m  →  优秀
  ⚠️ 正反向偏差 0.5~1.0 N·m          →  可接受，需补偿摩擦
  ❌ 正反向偏差 > 1.0 N·m 或曲线畸变  →  需排查原因

τ₃ 曲线:
  ✅ 光滑，两组数据趋势一致            →  优秀
  ⚠️ 两组数据几乎重合                 →  改变 q₂ 位姿重采
  ❌ 完全随机噪声                     →  检查传感器

τ₄~τ₆:
  ✅ 可见正弦趋势                     →  优秀
  ℹ️ 随机噪声                         →  用名义值
```

### 4.3 数据量参考

| 方案 | 数据量 | 耗时 |
|------|--------|------|
| 最小（仅 J2+J3） | ~200 组 | ~30 min |
| 完整（J1~J6） | ~338 组 | ~1 h |

## 5. 常见问题

### Q1：要拆夹爪吗？

**裸臂标定建议拆**。拆掉夹爪、相机等所有附件，标定裸臂参数。后续换任何末端设备，只需几分钟跑一个快速负载辨识，不用重新扫 6 个关节。

### Q2：换了末端执行器（夹爪/相机）要重新标定吗？

**不需要重新扫关节**。换末端后，走 5~6 个不同姿态，测力矩与裸臂预测对比，差值就是负载的重力矩，一步算出负载质量×质心。全程几分钟。

### Q3：每个点采多少帧？

- 大关节（J2, J3）：15~20 帧取平均
- 小关节（J4~J6）：20~30 帧（信噪比差，多采）

### Q4：速度设多慢才够？

$$\boxed{\text{VEL} \leq 0.15 \text{ rad/s},\quad \text{ACC} \leq 0.3 \text{ rad/s}^2}$$

目标是让惯性力 << 重力力矩，保证测量值近似等于纯重力矩 $\tau_g(q)$。

### Q5：夹爪装在 q6 上，标定时怎么处理 q6 的位姿？

夹爪是第 7 个独立关节。标定裸臂时，将夹爪拆下，link 6 只包含电机自身质量。后续装回夹爪后，通过末端快速标定得到夹爪的参数，与裸臂参数叠加使用。
