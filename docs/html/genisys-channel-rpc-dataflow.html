Genisys · Communication Data Flow

通信数据流：RPC 直达、500Hz 通道与 ROS2 出口

Genisys 是一条 500Hz 实时控制回路：指令从 HTTP、ROS2 或 zenoh 进来，状态在进程内 local 通道闭环，经 ROS2ProxyModule 转成标准消息交给 ROS2 生态。

  • HTTP
  • ROS2 srv
  • Zenoh
  • Protobuf
  • DDS

RPC 受理即返回

9 个 srv：MoveJ / MoveJPose / MoveJMulti / MoveJPoseMulti / MoveL / MoveLMulti / GripperPos / GripperForce / IKCheck。成功受理返回 error.code = 0 与 task_id，不阻塞到运动结束； 完成或失败经 /genisys/task_context（50Hz）按 task_id 归并通知。

AimRT 本身兼容 ROS2

同一批 srv 既在 HTTP :50080 上以 /rpc/genisys_msgs/srv/<方法> 可达，也由 ros2 后端暴露成 /genisys/srv/<方法>。普通 cfg 的通道走 Zenoh，_ros2 cfg 换成 ROS2 话题与服务 —— 这一段完全不经过 Proxy。

500Hz 闭环，real 与 sim 共用契约

joint_cmd / joint_state 走进程内 local 通道，ControlModule 与执行后端 首尾相接；后端由 cfg 选择 ActuatorModule（真机 CANFD）或 MujocoSimModule（MuJoCo），话题名、消息类型、 频率完全一致，切换只改配置。

ROS2ProxyModule 只补一个环

订阅 protobuf 话题，转成 sensor_msgs/JointState 与 geometry_msgs/PoseStamped， 按 100Hz 发布到 /joint_states、/tcp_pose、/flange_pose。 rviz2 可直接显示；tcp_pose_expected 这条桥目前关闭（enable: false），MoveIt2* 仍需使用方提供 robot_description 与 controller 配置。
