Genisys · Architecture

架构：三模块、两库、一份契约

Genisys 是跑在 AimRT 上的六轴机械臂控制栈：三个模块分别管 RPC 与控制回路、执行、ROS2 适配； 算法与驱动收在 genisys-core 子模块里，真机与仿真只差一个执行后端。

  • AimRT
  • ROS2
  • genisys-core
  • YAML cfg

模块与动态库

libarm_control_pkg.so 注册 ControlModule 与 ActuatorModule；ROS2ProxyModule 在独立的 libros2_proxy_pkg.so 里，只有 _ros2 cfg 才加载 —— 不带 ROS2 的部署可以少一份依赖。

real / sim 只换执行后端

真机用 ActuatorModule：500Hz 下发 CANFD、回读关节状态；仿真把 ActuatorModule 关掉，换官方 libmujoco_sim_pkg.so 的 MujocoSimModule。ControlModule、通道契约、Proxy 都不变。

算法与驱动在子模块

genisys-core 以 git 子模块引入：arm_control 负责运动学、逆解、轨迹与状态机， actuator 负责 GeniArm 的 CANFD 驱动与夹爪。上层只依赖它们的头文件。

契约与配置

genisys_msgs 提供 9 个 srv（含 ros2 gencode）与 JointState / Pose 类型， src/protocols/pb 提供 Pose / PoseStamped 的 protobuf。两层 cfg 决定插件、executor、通道后端， 以及限位、MDH、ik_mode、tool。
