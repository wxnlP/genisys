ROS2 Compatible

ROS2 兼容层 · ROS2ProxyModule

genisys 不是“能对接 ROS2”，而是本身就作为一个 ROS2 节点参与通信：内部 protobuf 话题由 ROS2ProxyModule 转成标准 ROS2 消息并按固定频率发布，9 个 srv 由 ros2 后端暴露成 ROS2 服务。ROS2 侧不需要任何适配代码——ros2 topic echo、rviz2、MoveIt2 拿到的是标准的 sensor_msgs/JointState 与 geometry_msgs/PoseStamped。

启动方式：用带 _ros2 后缀的配置启动即可（geniarm_real_gripper_with_gravity_ros2.yaml / geniarm_sim_gripper_with_gravity_ros2.yaml，直接 ./pkg_start.sh <cfg>）。 启动哪些话题的桥接，由 ROS2ProxyModule.bridges 里每条的 enable 决定： 

ROS2ProxyModule:
  publish_executor_name: ros2_proxy_executor
  publish_frequency: 100
  bridges:
    - type: joint_state
      sub_topic: /genisys/joint_state      # 要桥接的内部话题
      pub_topic: /joint_states            # 发布到的 ROS2 话题
      enable: true                        # 启动
    - type: pose_stamped
      sub_topic: /genisys/tcp_pose
      pub_topic: /tcp_pose
      enable: true
    - type: pose_stamped
      sub_topic: /genisys/tcp_pose_expected
      pub_topic: /tcp_pose_expected
      enable: false                       # 不启动
    - type: pose_stamped
      sub_topic: /genisys/flange_pose
      pub_topic: /flange_pose
      enable: true
